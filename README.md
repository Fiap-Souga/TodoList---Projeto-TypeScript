# TodoList - Projeto TypeScript

Este projeto é uma aplicação web de lista de tarefas desenvolvida com React + TypeScript + Vite e estilizada com Tailwind CSS. A interface permite criar, concluir e excluir tarefas, além de categorizar cada item por prioridade.

## Descrição do projeto

A aplicação foi criada para demonstrar o uso de React com TypeScript em um fluxo simples de gerenciamento de tarefas. Ela é ideal para estudos de componentes, estados, eventos e estrutura de interface moderna.

### Funcionalidades

- Adicionar novas tarefas;
- Definir prioridade: baixa, média ou alta;
- Marcar tarefas como concluídas;
- Excluir tarefas da lista;
- Interface responsiva e visual moderna;
- Estrutura organizada para facilitar manutenção e evolução.

## Stack utilizada

- React
- TypeScript
- Vite
- Tailwind CSS

## Pré-requisitos

Antes de iniciar, certifique-se de ter instalado:

- Node.js 18+;
- npm ou yarn.

## Instalação

1. Clone o repositório:

```bash
git clone https://github.com/Fiap-Souga/TodoList---Projeto-TypeScript
cd TodoList---Projeto-TypeScript
```

2. Instale as dependências:

```bash
npm install
```

3. Inicie o projeto em modo de desenvolvimento:

```bash
npm run dev
```

4. Acesse no navegador:

```bash
http://localhost:5173
```

## Scripts disponíveis
